설치

1
레포 clone
원하는 위치에 clone한다. 아래는 권장 경로.
필수
git clone https://github.com/jojo-dan/claude-code-statusline.git ~/.claude/statusline
2
settings.json 등록
~/.claude/settings.json에 statusLine command를 추가한다.
필수
{ "statusLine": { "command": "bash ~/.claude/statusline/scripts/statusline.sh" } }
Note: Claude Code가 stdin으로 JSON을 전달하고, stdout을 statusline 영역에 표시한다.
3
Claude Code 재시작 — 끝
Claude Code를 재시작하면 모든 기능이 즉시 동작한다.
필수 자동 반영
📂 my-project  opus4.6 ⚡hi 1000k
CTX ▰▰▱▱▱▱▱▱▱▱▱▱▱▱▱  12%  24k/200k
5H  ▰▰▰▱▱▱▱▱▱▱▱▱▱▱▱  16%  ↻ 4h39m
7D  ▰▰▰▰▰▰▱▱▱▱▱▱▱▱▱  39%  ↻ 5d21h
done  main
5H/7D 사용량은 Claude Code 로그인 시 OS에 저장된 토큰을 자동으로 읽어 동작한다. 추가 설정 불필요.
Fallback: credential store 접근이 안 되는 환경에서는 export CLAUDE_OAUTH_TOKEN="..."을 셸 프로필에 추가. 토큰을 가져올 수 없으면 5H/7D 바만 미표시, 나머지는 정상 동작.
3단계로 설치 완료. 아래는 선택 커스터마이징.
4
커스터마이징 (선택)
settings.json의 statusline 객체로 개별 행을 토글할 수 있다.
선택
// ~/.claude/settings.json { "statusline": { "ctx": true, // CTX 바 "5h": true, // 5H 사용량 바 "7d": false, // 7D 사용량 바 (끄기) "branch": true // 브랜치 + phase 행 } }
세션 단위 비활성화: CLAUDE_STATUSLINE_OFF=1
