Installation

1
Clone the repo
Clone to any location. Below is the recommended path.
Required
git clone https://github.com/jojo-dan/claude-code-statusline.git ~/.claude/statusline
2
Register in settings.json
Add the statusLine command to ~/.claude/settings.json.
Required
{ "statusLine": { "command": "bash ~/.claude/statusline/scripts/statusline.sh" } }
Note: Claude Code pipes JSON via stdin, and displays stdout in the statusline area.
3
Restart Claude Code — done
Restart Claude Code and everything works immediately.

5H/7D usage reads tokens stored by your OS when you log in to Claude Code. No extra setup needed.
Fallback: If credential store access is unavailable, add export CLAUDE_OAUTH_TOKEN="..." to your shell profile. When the token can't be retrieved, only the 5H/7D bars are hidden — everything else works normally.
Installation complete. Optional customization below.
4
Customization (optional)
Toggle individual rows via the statusline object in settings.json.
Optional
// ~/.claude/settings.json { "statusline": { "ctx": true, // CTX bar "5h": true, // 5H usage bar "7d": false, // 7D usage bar (off) "branch": true // branch + phase row } }
Per-session disable: CLAUDE_STATUSLINE_OFF=1
